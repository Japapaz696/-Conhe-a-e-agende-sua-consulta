# Links da Psicóloga Verônica

Landing page compacta no formato link-in-bio para centralizar os canais profissionais de Verônica Reis Santana.

## Objetivo

Facilitar o acesso ao agendamento, WhatsApp, Instagram e website institucional em uma experiência direta e responsiva.

## Tecnologias

HTML, CSS e JavaScript, sem dependências ou etapa de build.

## Como executar

Abra o `index.html` no navegador ou sirva a pasta com um servidor estático.

## Site principal

[site-veronica.onrender.com](https://site-veronica.onrender.com)

## Observação

O nome atual do repositório foi preservado para não afetar links e possíveis deploys. A sugestão de renomeação para `veronica-link-bio` está registrada nas ações manuais.
